# kuwabaky.github.io

`https://kuwabaky.github.io/` の直下に置く必要があるファイルのためのリポジトリです。

- `app-ads.txt` — Google AdMob の app-ads.txt。App Store の「マーケティング URL」(`https://kuwabaky.github.io/gyoreki/`)のホスト直下を AdMob が確認するため、ここに置いています。AdMob のパブリッシャー ID が変わったとき、または広告ネットワークを足したときに更新します。

アプリの公開ページ(サポート・利用規約・プライバシーポリシー)は、アプリごとのリポジトリにあります(例: [kuwabaky/gyoreki](https://github.com/kuwabaky/gyoreki))。
